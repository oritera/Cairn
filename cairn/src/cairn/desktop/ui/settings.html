How agents run

Local mode runs the agent CLIs installed on this PC. Container mode runs each project in a Linux container (needs Docker Desktop).

Each project gets its own subfolder here. Agents can read and write inside it.

App

Changing the server port takes effect the next time Cairn starts.

Local only (127.0.0.1). A free port is used if this one is taken.

Files

API keys are stored in Windows Credential Manager (under “Cairn”), not in these files.

Concurrency

In local mode all workers share this PC, so keep these modest.

Task timeouts (seconds)

Bootstrap tries to solve a project directly; Reason plans next steps; Explore carries one step out. “Conclude” is the extra time an agent gets to summarise after the main timeout.

Health checks

Local mode always checks that the CLIs are installed at startup.

Environment for all workers

Added to every worker's environment, for example an outbound proxy (HTTPS_PROXY). Worker-specific values win. Names containing KEY, TOKEN, SECRET or PASSWORD are stored in Credential Manager.

Container mode

Only used when the execution mode is “Container”. Requires Docker Desktop (WSL 2, Linux containers) and API settings for every worker.

Under Docker Desktop, “host” is the Docker VM's network.
Space-separated. Only add what tasks truly need.
